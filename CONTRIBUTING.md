# Contributing

Iteriq is currently a personal project in active development. Suggestions, bug reports, and focused pull requests are welcome.

1. Open an issue describing the bug or improvement before making substantial changes.
2. Do not commit credentials, API keys, or `.env` files.
3. Keep changes focused and explain how to test them.
4. Run `npm run check`, `npm test`, and `npm run test:integration` before submitting a pull request.

AI-generated feedback should be tested with both correct and incorrect student submissions; a plausible response is not necessarily an accurate one.
